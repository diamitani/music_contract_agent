## Notes for the drafting agent

- This is the shortest, fastest document in the library — most artists
  need it finished in one sitting, right after a session.
- Percentages must sum to exactly 100%. If the user gives you numbers
  that don't add up, flag it before finalizing rather than silently
  adjusting anyone's share.
- "Role" is not in the original template but should be added by default —
  it prevents later disputes about who did what, and costs nothing to
  include.
- If a beat was purchased under a separate beat license (not co-written),
  that beatmaker is usually NOT listed on the split sheet as a co-writer
  unless the license explicitly grants a percentage of the composition.
  Ask before assuming.
- No sample-clearance language here should be treated as clearance itself
  — it is a warranty, not a substitute for actually clearing a sample.
- This document splits the **composition/publishing**, not the **master
  recording**. If the group also needs to divide master ownership or
  streaming-royalty splits from a specific recording, that is a separate
  understanding (often handled in a Production Agreement or Artist
  Label Agreement) — say so if the user seems to be conflating the two.
