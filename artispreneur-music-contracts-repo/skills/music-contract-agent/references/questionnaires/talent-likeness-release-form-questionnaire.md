# Talent / Likeness Release Form — How to Use This Template & Questionnaire

Source template: `references/templates/talent-likeness-release-form.md`

## When to use this document

Use this agreement when the deal involves: Talent (person appearing) and Producer/Company using the likeness.

## What this contract type affects

- Grant of name/image/likeness/voice for a specific use
- Compensation, if any
- Territory and term of the release

## Step 1 — Find out who's asking

Confirm which side of the deal the user represents (Talent (person appearing) and Producer/Company using the likeness). Artist-protective
defaults in this skill are written from the perspective of the independent artist/
creator side of the deal. If the user is the other party (the hiring/paying side),
say so plainly and adjust: still be fair and accurate, but don't silently apply
artist-favoring defaults to someone who isn't the artist without telling them.

## Step 2 — Ask only what's missing

Use these grouped questions. Skip anything already answered in the conversation,
uploaded files, or pasted messages.

**Parties**
- Full legal names of all parties (and stage/business names)
- Notice addresses/emails
- Entity/signatory authority, if a company or LLC is involved

**Project & Money**
- Flat fee, if any, or confirmation this is unpaid/for exposure (flag if unpaid and commercial use is broad)

**Rights**
- Scope of use — specific project only, or broad/perpetual/all-media use. Perpetual releases for no or minimal pay are a common artist-risk pattern and should be flagged.

**Control & Risk**
- Whether the talent can revoke consent, and any context restrictions (e.g., not for political or competing-brand use)

## Step 3 — Watch for these risk patterns

**Red flag:** perpetual, worldwide, all-media likeness release for free or a small flat fee with no context restriction.
**Yellow:** no expiration or defined project scope — release could be reused for unrelated future projects.

## Contract-specific questions to ask

- What specific project/use is this release for?
- Is there compensation, and is it a flat fee or ongoing?
- Should the release be limited to this project, or does the user intend broader use?

## Delivery checklist

- [ ] All placeholders replaced (no blank underscores or `[BRACKETS]` left in the final draft)
- [ ] Money terms consistent everywhere they appear in the document
- [ ] Rights grant does not contradict the ownership section
- [ ] Term/termination/renewal dates don't conflict
- [ ] Signature blocks match the named parties exactly
- [ ] Attorney-review notice included per `references/05-safety-and-legal-boundaries.md`
- [ ] If any risk flag above is Red, the attorney-review recommendation is called out explicitly in the delivery, not buried in the fine print
