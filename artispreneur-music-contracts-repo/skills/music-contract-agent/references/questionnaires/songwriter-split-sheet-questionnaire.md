# Songwriter Split Sheet (Detailed / PRO-Registration) — How to Use This Template & Questionnaire

Source template: `references/templates/songwriter-split-sheet.md`

## When to use this document

Use this instead of the quick `split-sheet.md` when the song is about to be
registered with a Performing Rights Organization (ASCAP/BMI/SESAC), released
commercially, or when any writer already has a publishing deal that needs to
be reflected. This version captures the data PROs and publishers actually
need to route royalties correctly.

## What this contract affects

- Composition/publishing ownership and the specific lyrics/music split within it
- Royalty registration and collection setup with PROs and publishers

## Step 1 — Ask only what's missing

**Song & Session**
- Song title, session date(s), recording artist, record label (if any)
- Studio name, address, and phone (some publishers/PROs still want this on file)
- Whether the composition contains a sample, and if so, the originating artist/album

**Per Writer (repeat for each contributor)**
- Full legal name, address, phone
- Publishing company, if the writer already has one — and if a third party (a publisher) is entitled to a percentage, capture that party's info too
- Publishing percentage vs. writer's share (these are often tracked separately: "writer's share" and "publisher's share")
- PRO affiliation: ASCAP, BMI, or SESAC
- Ownership percentage broken down by lyrics and music if the contributions were not evenly split across both
- CAE/IPI number, if the writer has one (needed for PRO registration; if they don't know it, they can register with their PRO to get one)
- Birthdate (used for identity verification with some PROs — flag as sensitive and only collect if the writer is comfortable providing it in this document; note that Social Security numbers should generally NOT be put in a document that may be shared broadly — recommend collecting SSN/tax ID separately and securely rather than embedding it in the split sheet itself)

## Step 2 — Watch for these risk patterns

- **Yellow:** total ownership percentages across all writers don't sum to 100% — verify the math before finalizing.
- **Yellow:** a writer lists a publishing percentage without clarifying whether that's carved out of their own writer's share or in addition to it — clarify which.
- **Privacy flag:** this template's original field list includes a Social Security Number field. Recommend NOT including full SSNs in a document that will be emailed, stored broadly, or shared with multiple parties. Suggest collecting tax ID information through a separate, more secure channel (e.g., a W-9 sent directly to whoever handles royalty payments) instead of embedding it here.

## Delivery checklist

- [ ] Percentages sum to 100% across all writers
- [ ] PRO affiliation captured for each writer (or noted as "not yet registered")
- [ ] Sample disclosure addressed
- [ ] SSN/sensitive ID fields either omitted or the user has been warned about how this document will be stored/shared
- [ ] Signature line for every writer
